# mzg — Механика жидкости и газа: экспериментальный практикум

Статический учебный сайт (чистые HTML/CSS/JS, без сборки): четыре лабораторные
работы практикума кафедры гидроаэромеханики СПбГМТУ, разобранные по шагам, —
с виртуальными опытами (живые анимации установок) и курсом теории из восьми глав.

**Прод:** https://shadeswd.duckdns.org/mzg/

## О сайте
Гидростатика, уравнение Бернулли, потери напора, обтекание тел. Каждая работа
разобрана по единой схеме: схема установки (перерисована в векторе), формулы с
пояснением каждого символа, «решение по шагам» с подстановкой реальных чисел
из журнала измерений, графики точно по экспериментальным точкам. Обработка
ведётся по методике кафедрального пособия, а типичные ошибки обработки разобраны
отдельными методическими примечаниями. На каждой работе есть **виртуальный опыт** — анимация
установки, с которой можно снять собственные отсчёты и получить свой результат
(вплоть до переноса тарировочного коэффициента из лаб. 1 в лаб. 3).

## Содержание
- `site/` — сам сайт (без сборки, чистые HTML/CSS/JS)
  - `index.html` — обзор практикума и навигация
  - `lab1.html` — тарировка микроманометра: коэффициент K = ΔP/Δu ≈ 4,3 Па/мВ
  - `lab3.html` — движение жидкости по трубопроводу: диаграмма Бернулли,
    ζ расходомера, коэффициент трения λ
  - `lab4.html` — сопротивление шара в аэродинамической трубе: Cx(Re)
  - `lab5.html` — давление по телу вращения: эпюра Cp(x) по 14 дренажным точкам
  - `theory.html` — оглавление курса теории; главы `t-props`, `t-forces`,
    `t-statics`, `t-kinematics`, `t-bernoulli`, `t-losses`, `t-similarity`,
    `t-boundary`
  - `sources.html` — источники (протоколы измерений практикума и учебники)
  - `assets/` — `style.css`, `site.js` и движки виртуальных опытов
    (`virt-common.js`, `virt-lab1.js`, `virt-lab3.js`, `virt-lab4.js`,
    `virt-lab5.js`)
- `deploy/` — docker-compose (nginx:alpine, 127.0.0.1:8066) + конфиг nginx
- `tests/` — тесты целостности сайта (pytest)

## Запуск локально
```bash
cd deploy && docker compose up -d   # проект называется mzg (name: обязателен!)
```
Сайт поднимается на 127.0.0.1:8066; наружу отдаётся через nginx хоста
(location /mzg/ в site duckdns).

## Тесты
```bash
python3 -m pytest tests/
```
Переносимый набор структурных тестов: каждая HTML-страница проверяется на
корректный разбор, отсутствие дублей id и целостность локальных ссылок/ассетов
(с учётом clean-URL nginx `try_files $uri $uri.html $uri/`), каждый JS —
на синтаксис через `node --check`. Тот же прогон крутится в GitLab CI
(`.gitlab-ci.yml`).
