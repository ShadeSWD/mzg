Лаб. 5. Распределение давления по телу вращения

Осесимметричное тело длиной 220 мм с 14 дренажными отверстиями вдоль образующей обдувается потоком ≈24 м/с. Каждое отверстие по очереди подключается к датчику давления — получается распределение давления по поверхности, которое приводится к безразмерному коэффициенту Cp. Это тот самый эксперимент, из которого видно, откуда у тела берётся сопротивление формы.

Схема: тело с дренажными точками

Тело вращения в потоке аэродинамической трубы; контур построен по реальной таблице профиля (x, R) из практикума, масштаб 2:1. Красные точки — дренажные отверстия: каждое поочерёдно соединяется трубкой с датчиком давления Д.Д., сигнал которого через тарировочный коэффициент (лаб. 1) переводится в паскали. Скорость набегающего потока v∞ контролируется трубкой Пито. Условия опыта: воздух, ρ = 1,2 кг/м³, t = 21 °C.

Формулы

v∞ = 1,01·√(2ΔPср/ρ);    Cp = (P − P∞) / (0,5·ρ·v∞²),

где ΔPср — среднее показание трубки Пито (скоростной напор набегающего потока), 1,01 — тарировочный множитель трубки, P − P∞ — измеренная разность давления в дренажной точке и статического давления невозмущённого потока. Cp = +1 означает полное торможение (критическая точка), Cp < 0 — разгон потока и разрежение (см. теорию).

Решение по шагам

v∞ = √(2ΔPср/ρ) = √(2·354/1,2) = 24,3 м/с (с множителем трубки 1,01 — 24,5 м/с; отчёт принял 24,3, разница 1 %)
q = 0,5·ρ·v∞² = 0,5·1,2·24,3² = 354 Па (скоростной напор; он же ΔPср)
Cp (точка 3, x = 5 мм) = (P−P∞)/q = 210/354 = +0,59
Cp (точка 7, мидель) = −179/354 = −0,51
Cp (точка 14, корма) = −4/354 = −0,01 ≈ 0

Про обработку отчёта — два примечания. (1) В знаменателе Cp отчёт использует 388 Па, хотя скоростной напор по его же данным 0,5ρv∞² = 354 Па (361 Па с множителем трубки) — знаменатель завышен на ~10 %, в таблице приведён честный пересчёт на 354 Па. (2) В носовой критической точке (т. 1, x = 0) ожидается Cp ≈ +1 — полное торможение потока, а измерено лишь 0,014; максимум пришёлся на т. 3. Почти наверняка носовое дренажное отверстие засорено или негерметично — типичный дефект дренированных моделей; форма остальной эпюры физически правильная.

Эпюра Cp(x)

Эпюра коэффициента давления по длине тела (пересчёт со знаменателем 354 Па); серый силуэт внизу — то же тело в том же масштабе по x. Классическая картина обтекания: подпор на носовой части (Cp > 0), разгон потока и максимум разрежения у миделя (Cp ≈ −0,5), затем торможение и почти полное восстановление давления к корме (Cp ≈ 0) — признак безотрывного обтекания хорошо спрофилированного тела: сопротивление формы мало́, преобладает трение.
