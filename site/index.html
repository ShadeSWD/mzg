Как устроен разбор каждой работы

Каждая страница собрана по одной схеме: схема установки нарисована заново в векторе по описанию из практикума; формулы даются с пояснением каждого символа; «решение по шагам» подставляет в формулы реальные числа из журнала измерений — формула, серым подстановка, жирным результат; графики построены точно по экспериментальным точкам. Там, где в студенческой обработке есть арифметические ошибки (а они есть в лаб. 3, 4 и 5), приведён честный пересчёт и примечание, откуда взялась ошибка — это само по себе полезное упражнение.
