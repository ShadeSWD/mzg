Лаб. 3. Движение жидкости по трубопроводу

Вентилятор гонит воздух по трубе ⌀96 мм длиной около девяти метров. Вдоль трубы через каждые 150 мм — дренажные штуцеры: подключая к ним датчик давления, снимаем избыточное давление по длине и строим диаграмму Бернулли. Из неё достаём коэффициент местных потерь ζ расходомера (трубы Вентури) и коэффициент трения λ прямых участков.

Схема установки

Вентилятор через конфузор разгоняет воздух в трубу постоянного диаметра D = 96 мм. Датчик Д.Д.1 меряет перепад давления на сужении трубы Вентури (по нему считается расход), датчик Д.Д.2 поочерёдно подключается к дренажным штуцерам и снимает избыточное давление в сечениях по длине; оба датчика оцифровываются компьютером. Условия опыта: воздух, ρ = 1,184 кг/м³, ν = 15,06·10⁻⁶ м²/с, t = 25 °C.

Формулы

Уравнение Бернулли для вязкой жидкости между сечениями 1 и 2 (труба горизонтальна, z = const; вывод членов — в теории):

P₁/(ρg) + α₁v₁²/(2g) = P₂/(ρg) + α₂v₂²/(2g) + Hп

Расход через трубу Вентури с коэффициентом расхода μ = 0,4 (учитывает сжатие струи и потери в сужении):

Q = μ·S·√(2ΔP/ρ), откуда средняя скорость vср = Q/S.

Местные потери на расходомере — по скачку полного напора HМ на диаграмме Бернулли: ζ = HМ·2g/v².

Трение по длине — из формулы Дарси–Вейсбаха по наклону пьезометрической линии на прямом участке длиной L: λ = Hl·2g·D/(v²·L).

Решение по шагам

S = πD²/4 = π·0,096²/4 = 0,0072 м²
Q = μS√(2ΔP/ρ) = 0,4·0,0072·√(2·490/1,184) = 0,4·0,0072·28,8 = 0,083 ≈ 0,08 м³/с
vср = Q/S = 0,083/0,0072 = 11,5 м/с
v²/2g = 11,5²/(2·9,81) = 6,74 м (скоростная высота)
Re = vD/ν = 11,5·0,096/(15,06·10⁻⁶) = 7,3·10⁴ — турбулентный режим
h₁ = P₁/(ρg) = 452/(1,184·9,81) = 38,9 м (и так для каждого сечения — см. таблицу)
HМ = H₃ − H₄ = 39,0 − 16,3 = 22,7 м (скачок полного напора на расходомере)
ζ = HМ·2g/v² = 22,7/6,74 = 3,4
Hl1 = h₁ − h₃ = 38,9 − 32,3 = 6,6 м (участок до расходомера, L₁ = 4435−1735 = 2,7 м)
λ₁ = Hl1·2g·D/(v²·L₁) = 6,6·0,096/(6,74·2,7) = 0,035
Hl2 = H₄ − H₆ = 16,3 − 6,74 = 9,6 м (участок после расходомера, L₂ = 9035−5135 = 3,9 м)
λ₂ = Hl2·2g·D/(v²·L₂) = 9,6·0,096/(6,74·3,9) = 0,035

Высоты пересчитаны честно: h = Pизб/(ρg) при ρ = 1,184 кг/м³ и полный напор H = h + 6,74 м. Сечения 3 и 4 — крайние штуцеры до и после трубы Вентури.

Про ошибки исходного отчёта. В отчёте к пьезометрическим высотам прибавлена скоростная высота 2,27 м вместо посчитанной там же 6,74 м, а коэффициент трения получен λ = 0,001. Честный пересчёт по λ = Hl·2g·D/(v²·L) с L между крайними точками участка даёт λ ≈ 0,035 на обоих прямых участках — согласованно, что само по себе хороший признак. Значение 0,001 физически невозможно (меньше λ гладкой трубы при любых Re). Для сравнения: формула Блазиуса для гладкой трубы при Re = 7,3·10⁴ даёт λ ≈ 0,019; измеренное выше — сказываются штуцеры, стыки и шероховатость, но порядок величины сходится.
