Движение жидкости по трубопроводу

Вентилятор гонит воздух по трубе ⌀96 мм длиной около девяти метров. Вдоль трубы через каждые 150 мм — дренажные штуцеры: подключая к ним датчик давления, снимаем избыточное давление по длине и строим диаграмму Бернулли. Из неё достаём коэффициент местных потерь ζ расходомера (трубы Вентури) и коэффициент трения λ прямых участков.

Схема установки

Вентилятор через конфузор разгоняет воздух в трубу постоянного диаметра D = 96 мм. Датчик Д.Д.1 меряет перепад давления на сужении трубы Вентури (по нему считается расход), датчик Д.Д.2 поочерёдно подключается к дренажным штуцерам и снимает избыточное давление в сечениях по длине; оба датчика оцифровываются компьютером. Условия опыта: воздух, \(\rho = 1{,}184\) кг/м³, \(\nu = 15{,}06\cdot 10^{-6}\) м²/с, t = 25 °C.

Формулы

Уравнение Бернулли для вязкой жидкости между сечениями 1 и 2 (труба горизонтальна, z = const; вывод членов — в теории):

$$\dfrac{P_1}{\rho g} + \dfrac{\alpha_1 v_1^2}{2g} = \dfrac{P_2}{\rho g} + \dfrac{\alpha_2 v_2^2}{2g} + H_{\text{п}}$$

Расход через трубу Вентури с коэффициентом расхода \(\mu = 0{,}4\) (учитывает сжатие струи и потери в сужении):

$$Q = \mu\cdot S\cdot\sqrt{2\Delta P/\rho},$$ откуда средняя скорость \(v_{\text{ср}} = Q/S\).

Местные потери на расходомере — по скачку полного напора HМ на диаграмме Бернулли: \(\zeta = H_{\text{М}}\cdot 2g/v^2\).

Трение по длине — из формулы Дарси–Вейсбаха по наклону пьезометрической линии на прямом участке длиной L: \(\lambda = H_l\cdot 2g\cdot D/(v^2\cdot L)\).

Решение по шагам

\(S = \pi D^2/4\) = \(\pi\cdot 0{,}096^2/4\) = \(0{,}0072\) м²
\(Q = \mu S\sqrt{2\Delta P/\rho}\) = \(0{,}4\cdot 0{,}0072\cdot\sqrt{2\cdot 490/1{,}184} = 0{,}4\cdot 0{,}0072\cdot 28{,}8\) = \(0{,}083 \approx 0{,}08\) м³/с
\(v_{\text{ср}} = Q/S\) = \(0{,}083/0{,}0072\) = \(11{,}5\) м/с
\(v^2/2g\) = \(11{,}5^2/(2\cdot 9{,}81)\) = \(6{,}74\) м (скоростная высота)
\(\mathrm{Re} = vD/\nu\) = \(11{,}5\cdot 0{,}096/(15{,}06\cdot 10^{-6})\) = \(7{,}3\cdot 10^4\) — турбулентный режим
\(h_1 = P_1/(\rho g)\) = \(452/(1{,}184\cdot 9{,}81)\) = \(38{,}9\) м (и так для каждого сечения — см. таблицу)
\(H_{\text{М}} = H_3 - H_4\) = \(39{,}0 - 16{,}3\) = \(22{,}7\) м (скачок полного напора на расходомере)
\(\zeta = H_{\text{М}}\cdot 2g/v^2\) = \(22{,}7/6{,}74\) = \(3{,}4\)
\(H_{l1} = h_1 - h_3\) = \(38{,}9 - 32{,}3\) = \(6{,}6\) м (участок до расходомера, \(L_1 = 4435-1735\) мм \(= 2{,}7\) м)
\(\lambda_1 = H_{l1}\cdot 2g\cdot D/(v^2\cdot L_1)\) = \(6{,}6\cdot 0{,}096/(6{,}74\cdot 2{,}7)\) = \(0{,}035\)
\(H_{l2} = H_4 - H_6\) = \(16{,}3 - 6{,}74\) = \(9{,}6\) м (участок после расходомера, \(L_2 = 9035-5135\) мм \(= 3{,}9\) м)
\(\lambda_2 = H_{l2}\cdot 2g\cdot D/(v^2\cdot L_2)\) = \(9{,}6\cdot 0{,}096/(6{,}74\cdot 3{,}9)\) = \(0{,}035\)

Высоты пересчитаны честно: \(h = P_{\text{изб}}/(\rho g)\) при \(\rho = 1{,}184\) кг/м³ и полный напор \(H = h + 6{,}74\) м. Сечения 3 и 4 — крайние штуцеры до и после трубы Вентури.

Две проверки, которые стоит сделать всегда. Первая — скоростная высота: к пьезометрическим высотам прибавляется именно \(v^2/2g\), посчитанная по той же скорости, что и расход (здесь 6,74 м); подстановка сюда скоростной высоты другого сечения — самая частая ошибка построения линии полного напора. Вторая — порядок коэффициента трения: пересчёт по \(\lambda = H_l\cdot 2g\cdot D/(v^2\cdot L)\) с L между крайними точками участка даёт \(\lambda \approx 0{,}035\) на обоих прямых участках — согласованность двух независимых участков сама по себе хороший признак. Для сравнения, формула Блазиуса для гидравлически гладкой трубы при \(\mathrm{Re} = 7{,}3\cdot 10^4\) даёт \(\lambda \approx 0{,}019\); превышение объясняется штуцерами, стыками и шероховатостью. Значения порядка 0,001 физически невозможны — они меньше λ гладкой трубы при любых Re, и это первый признак ошибки в арифметике.
